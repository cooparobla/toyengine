# Add terrain

Read **`toyengine/world/README.md`** (generation, tiling, styles, generators) and copy from
`assets/scenes/terrain_test/scene.yaml` (flat voxel style) or
`assets/scenes/terrain_smooth_test/scene.yaml` (styled tiles per kind). Parser:
`toyengine/scene/register.h` ("Terrain"); defaults in `toyengine/world/terrain_component.h` and
`terrain_sampler.h`.

## Minimal recipe

```yaml
- name: terrain
  components:
    - type: Transform
      position: { x: 0.0, y: 0.0, z: 0.0 }
      rotation: { x: 0.0, y: 0.0, z: 0.0 }
      scale: { x: 1.0, y: 1.0, z: 1.0 }
    - type: Terrain
      seed: 251
      grid_size: 64
      shape: continent          # rectangle | circle | triangle | continent | archipelago
      sea_level: 0.25
      terrain_roughness: 0.35
      river_count: 25
      tiles_per_grid_unit: 4
      tile_size: 1.0
      height_step: 1.0
      height_scale: 40.0
      chunk_size: 16
      view_radius: 3            # chunks streamed around the main camera
      side_mesh: tile_side_flat
      material:
        texture_albedo: textures/terrain_atlas.png
        texture_metallic_roughness: textures/terrain_atlas_mr.png
```

Key groups: generation (`seed`, `grid_size`, `sea_level`, `terrain_roughness`, `river_count`,
`shape`, `continent_count`, `continent_size_m`, `irregularity`, `coast_detail`,
`temperature_offset`); tiling (`tiles_per_grid_unit`, `tile_size`, `height_step`,
`height_scale`, `chunk_size`, `view_radius`, `max_wall_steps`, `soil_depth_steps`,
`greedy_merge`, `emit_bottom`, `max_chunk_jobs_per_frame`); look (`material`, `side_mesh`,
`sides { top, bottom, north, south, east, west }`, `styles { name: objects/tileset_x }`,
`kind_styles { default: name, <kind>: name }` with kinds grass, dirt, stone, sand, snow, rock,
water, ice, moss, clay, ash, salt -- always give `default`).

## Notes

- Chunks stream around the **main camera**: terrain_test orbits the camera around a
  `focus_marker` object with a FreeMover so the user can travel. Big `view_radius` x
  `chunk_size` costs generation time.
- Tile styles are object assets `assets/objects/tileset_*.yaml` (generated by
  `tools/gen_tile_styles.py`); Terrain reads each piece child's MeshRenderer `mesh_path` by
  piece name. Meshes `assets/meshes/tile_*`, atlases `assets/textures/terrain_atlas*` come from
  `tools/gen_tile_side_meshes.py`, `gen_tile_styles.py`, `gen_terrain_atlas.py` -- extend those
  generators rather than hand-editing their outputs.
- There are no terrain colliders yet: physics objects fall through.
- Large terrains want shadow tuning in scene settings (terrain_test uses `shadow_fit: focus`,
  `shadow_focus_radius`, `shadow_distance`).

## Verify

```sh
FRAMES=240 .claude/skills/create-scene/scripts/render_scene.sh <scene>    # chunks need frames to stream in
./build/toyengine_tests caml_roundtrips_every_asset
./build/toyengine_tests --group world
```

Look for holes (chunks not yet streamed -- give more frames), seams between chunks, and the
style per kind applied where expected.
